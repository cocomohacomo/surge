## Acquisition notes

1. The source register contains 50 distinct page URLs.
2. A number of pages are portals, indexes, or catalogue pages. Their listing structure is the test object; linked source material is not claimed to have been fully acquired unless listed separately.
3. W01, W08, W11, W12 and W25 are explicitly partial/dynamic in this capture. Their test is that SURGE marks incomplete capture honestly and does not infer missing content.
4. PDF_TEXT means the web extraction service returned readable PDF text. It does not imply every figure/image was OCR-verified.
5. The register records public URLs and short titles, not wholesale reproduced copyrighted page contents. Source-specific terms and reuse conditions remain applicable.
