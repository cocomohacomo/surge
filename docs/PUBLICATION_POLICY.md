# Publication and reuse policy

## Repository visibility

The repository is intended to be publicly readable. All branches, tags,
commits, pull requests, issues, discussions, workflow runs, and other GitHub
surfaces that GitHub makes public may be visible when repository visibility is
changed. Publication does not mean that every branch is stable or production
ready. Consult the branch and pull-request status before relying on a change.
